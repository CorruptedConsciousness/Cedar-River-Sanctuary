# Cedar River Sanctuary

An open-source wildlife observation and environmental monitoring station located near the Cedar River in Buckeye Township, Michigan.

The project combines live video, ambient audio, weather monitoring, and AI-powered wildlife detection into an openly accessible research and educational platform.

## Features

- 📹 Live wildlife cameras
- 🎙️ Ambient forest audio
- 🌦️ Real-time weather conditions
- 🐦 Wildlife observations
- 📊 Open ecological datasets
- 🧠 AI-assisted species detection
- 🌐 Public website

## Hardware

- Outdoor IP Cameras
- USB Microphone
- Weather Station
- Ethernet Network
- HP OmniStudio X Processing Server
